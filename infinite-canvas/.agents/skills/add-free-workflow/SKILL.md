# 添加自由工作流（add-free-workflow）

当用户要把自选的 ComfyUI 工作流（API 格式或 UI 工作流）加进画布时，用这个流程。

## 步骤

1. 确认工作流来源：用户上传的 JSON、剪贴板内容，或 ComfyUI 的「导出（API）」结果。
2. 解析成 API 格式：节点必须带 `class_type` 与 `inputs`；纯 UI 格式（含 `nodes`/`links`）需要转换。
3. 识别可绑定字段：提示词文本输入、负向提示词、宽高、步数、CFG、采样器、调度器、种子，以及图片/视频输入槽。
4. 映射到画布节点参数，写进 registry 条目的 `bindings`；未识别的输入保留原值，不要擅自改写。
5. 提交前用 `POST /api/setup/scan` 确认新增条目可被网关识别，再看 `/v1/models` 里是否出现。
6. 模板 JSON 里的模型名要跟本机 `object_info` 下拉一致；不一致时记录缺失项，不要静默替换。

## 注意

- 工作流里写死的采样步数与调度往往和底模绑定，换底模前先确认是否需要换 sigmas。
- 不要修改用户上传的原文件；派生版本另存。
